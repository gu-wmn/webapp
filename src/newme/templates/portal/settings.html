Global settings

These settings apply to all experiments. Changes take effect on the next run.

Global prompt template

Prepended to every LLM prompt, before the prompt-specific text. Use this for a shared system context or persona. Leave empty to skip.

Free text appendix

Appended to prompts using the None (free text) output format. Use this to add any shared closing instruction for unstructured responses. Leave empty to append nothing.

Simplified output appendix

Appended to prompts using the Simplified output format. Instructs the model on the JSON structure to return for utterance-level candidate hits, including utterance indices and an exact quote.

Detailed output appendix

Appended to prompts using the Detailed output format. Instructs the model to return span indices, exact quotes, and WMN type.

Default regex patterns

Used as the starting point when creating a new Regex prompt. Each pattern is a JSON object with label, pattern, and optional flags ("i" = case-insensitive, "s" = dot matches newline). Use \\b for word boundaries.
